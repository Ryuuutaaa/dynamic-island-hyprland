# UI / Layout preferences

- Dislikes large unused/empty space in UI layouts — flags when a view shows too little content ("terlalu memiliki banyak ruang kosong") and wants the layout improved to use the available area with useful information instead of just adding empty filler. Confidence: 0.65
- Prefers generous breathing room between adjacent UI elements: complains when spacing is too tight ("terlalu dekat spacing bar dan pengingat airnya") and expects gaps to be increased/adjusted rather than left cramped. Confidence: 0.6
- Evaluates UI as a product designer would — cares about space utilization, spacing, and visual balance across pages, not just whether features work. Confidence: 0.55
- Cares about animation quality: flags shape/panel transitions that are not smooth ("animasi perubahan bentuknya masih kurang smooth") and expects the transition itself to be fixed, not only the end state. Confidence: 0.6
- Does not accept "that's intentional / that's how it is" as closure for a motion artifact: when told a perceived "adjustment" is by design (overshoot tween, stepped radius interpolation, watchdog delay) or that the remainder is inherent, he still comes back asking for it to be smoothed ("apakah tidak bisa di perhalus gitu?", "masih ada adjustment melebar itu, bagaimana?"). Expect the transition to keep being refined (overlapping content removed, intermediate values interpolated) instead of being explained away. Confidence: 0.75
- Judges a transition by the whole enclosing container, not only its inner content: a card/window that visibly widens or stretches during or just after a collapse (extra headroom/overshoot padding leaking into the closing direction) is reported as a bug ("adjustment melebar itu"), just like a frame where the card is momentarily visible but empty (content swapped out before the new content appears). Confidence: 0.5
- Watches motion frame-by-frame with a skeptical eye: notices a sudden shift of content mid-transition (e.g. content jumping during hover-out) and asks whether it is intentional ("itu kayak semacam animasi adjustment gitu, apakah itu benar?") — expects every property to interpolate monotonically with no snapping, even for intermediate/secondary values like reserved space or margins. Confidence: 0.6
- Expects input isolation for on-screen overlays: while a widget/panel (e.g. the dynamic island) is open and being interacted with, key presses meant for it must be consumed and must NOT leak to the focused application (flagged as a concern that arrow keys pressed on the island also seek/scroll a playing YouTube video). Confidence: 0.7
- Expects interactive UI (nav pills, buttons) to stay anchored in place during layout/width transitions — any shift that makes clicks land inconsistently or drops the hover state is treated as a real bug, not cosmetic. Confidence: 0.65
- Prefers a "clean dan minimalis" visual language and asks for it explicitly by name when requesting new UI (e.g. Bluetooth row, notification popup, swaync control center); treats heavy borders, bold mono type, and inconsistent type scales as not matching. Confidence: 0.8
- Treats motion as part of the visual style, not a separate layer: when asking for a "clean minimalis" look he also specifies that the animation must suit that setup ("animasi yang cocok untuk setup tersebut") — expect restrained, subtle transitions tuned to the same aesthetic instead of default/bouncy ones. Confidence: 0.6
- Wants rows/elements hidden entirely when there is no data to show, instead of an empty placeholder or a disabled row ("jika tidak ada device yang connect jangan tampilkan"). Confidence: 0.7
- Keeps top-level navigation minimal: secondary content should be a contextual sub-view inside its parent page (lyrics opened from the music card, dot stays on music) rather than an extra page/slot in the bar. Confidence: 0.6
- Expects notification/popup UI to follow modern affordances: slide in/out, a visible X to dismiss, a progress bar showing remaining display time, click-through to open the source app, and icon-only buttons for system actions (e.g. a download glyph instead of an "Install" label). Confidence: 0.55
- Treats his own explicit toggles as authoritative: if he turns a global setting off (e.g. DND / Do-Not-Disturb), it must stay off. A background watchdog that silently re-enables it to serve the app's own need (suppressing its duplicate popup) is reported as a bug ("aku sudah mematikan DND, tapi lambangnya masih DND"). Prefer scoping the suppression to just what the app owns instead of overriding user state. Confidence: 0.7
- Expects notification content to be complete — sender AND the actual message body; a notification showing only who sent it is flagged as an issue worth root-cause investigation. Confidence: 0.55
